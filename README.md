# BiteSized-Media — Bitácora

Bitácora académica del pipeline de producción de video sintético para
**Edge Sight AI / Sentientum** (Scapder). Documenta, con evidencia real
(transcripciones, detección de silencio, videos antes/después), qué
funcionó y qué no al construir contenido narrado, doblado y subtitulado con
Higgsfield MCP + ffmpeg + whisper.cpp.

Dos propósitos:

- **Onboarding** para quien se sume al equipo (Content Lead, Full Stack
  Developer) en este proyecto.
- **Material de clase**: casos de uso reales de IA generativa aplicada,
  con los errores incluidos — no una demo prolija.

Sitio publicado vía GitHub Pages: **https://haroldsthid.github.io/BiteSized-Media-Bitacora/**

El repo de trabajo del pipeline (privado) es
[`scapder/BiteSized-Media`](https://github.com/scapder/BiteSized-Media).
